## 🎯 Interactive Features to Try

### 1️⃣ **Dark Mode Toggle**
   **Steps:**
   - Look at the top-right of the sidebar
   - Click the moon icon 🌙
   - Watch the entire interface smoothly transition to dark theme
   - Click the sun icon ☀️ to return to light mode
   - Refresh the page - your choice is remembered!

### 2️⃣ **Add Tasks & See Charts Update**
   **Steps:**
   - Click "Tasks" in the sidebar
   - Add a task: "Complete lab report"
   - Select category: "Assignment"
   - Mark it as complete (checkbox)
   - Go back to Dashboard
   - See the task count update to "1"
   - Scroll down - the bar chart now shows data!

### 3️⃣ **Enable Notifications**
   **Steps:**
   - Click "Pomodoro" in the sidebar
   - Click the blue "Enable Notifications" button
   - Browser will show a permission popup - click "Allow"
   - You'll immediately get a test notification!
   - Set focus time to 1 minute (for quick testing)
   - Click "Start"
   - Wait 1 minute
   - Get a notification even if browser is minimized!

### 4️⃣ **Explore All Modules**
   - **Tasks:** Add assignments with due dates
   - **Habits:** Create "Morning workout" habit
   - **Notes:** Write study notes
   - **Timetable:** Plan your weekly schedule
   - **Dashboard:** See all your stats and charts

## 🐛 Troubleshooting

**Charts not showing?**
→ Make sure you have internet connection (Chart.js loads from CDN)

**Notifications not working?**
→ Check browser settings → Site permissions → Allow notifications

**Dark mode not persisting?**
→ Check browser allows localStorage for this site

**Browser showing "http://" warning?**
→ Normal for local files - click "Advanced" → "Proceed"
